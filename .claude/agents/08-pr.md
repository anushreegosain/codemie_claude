## Step 5 — Create the GitHub PR

**Derive the PR title** from the first heading of `docs/agentic-sdlc/artifacts/<KEY>/requirements.md`.
The heading has the format `# Requirements — <KEY>: <Story Title>`. Strip the prefix to build:
```
feat(<KEY>): <story title in lowercase with first word capitalised>
```
Example: `# Requirements — KT-19: Inline Status Controls` → `feat(KT-19): Inline status controls`

**Get the current branch** (set as `HEAD_BRANCH`):
```bash
HEAD_BRANCH=$(git branch --show-current)
```

**Push the branch** if it has no upstream:
```bash
git push -u origin "$HEAD_BRANCH" 2>/dev/null || true
```

**Load GitHub credentials** — prefer `.env.local`, fall back to `.env.local.bak`:
```bash
ENV_FILE=".env.local"
[ ! -f "$ENV_FILE" ] && ENV_FILE=".env.local.bak"
source <(grep -E '^GITHUB_' "$ENV_FILE")
```

**Create the PR via GitHub REST API:**
```bash
PR_TITLE="feat(<KEY>): <derived title>"
PR_BODY=$(cat "docs/agentic-sdlc/artifacts/<KEY>/pr-description.md")

curl -s -X POST \
  -H "Authorization: Bearer $GITHUB_TOKEN" \
  -H "Accept: application/vnd.github+json" \
  -H "Content-Type: application/json" \
  "https://api.github.com/repos/$GITHUB_REPO_OWNER/$GITHUB_REPO_NAME/pulls" \
  -d "$(jq -n \
    --arg title "$PR_TITLE" \
    --arg body  "$PR_BODY" \
    --arg head  "$HEAD_BRANCH" \
    --arg base  "main" \
    '{title: $title, body: $body, head: $head, base: $base}')"
```

If the response JSON has no `html_url`, print the full response and stop — do not proceed to Step 6.

**Fallback:** if `curl` or `jq` are unavailable and `gh` is installed:
```bash
gh pr create --title "$PR_TITLE" --body "$PR_BODY" --base main
```
